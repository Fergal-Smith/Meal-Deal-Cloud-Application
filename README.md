
  # Interactive Grocery Mobile App

  This is a code bundle for Interactive Grocery Mobile App. The original project is available at https://www.figma.com/design/0d0KfnY0liZ8R5kV5771HI/Interactive-Grocery-Mobile-App.

  ## Description
  The Student Food Deals App is a web application designed to connect students with local food businesses offering discounted surplus     food. The aim is to help students access affordable meals while allowing businesses to reduce food waste by advertising unsold food at   reduced prices.

The application provides a platform where students can discover nearby food deals, while businesses can advertise and manage their available offers.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
